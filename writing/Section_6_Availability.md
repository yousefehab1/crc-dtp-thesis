# Data and code availability

The primary transcriptomic datasets are publicly available: GSE39582 and GSE50760 from the Gene Expression Omnibus, and the TCGA cohorts from the Genomic Data Commons, with clinical follow-up from the TCGA Clinical Data Resource (Liu et al. 2018). The analysis code and the supplementary result tables (Appendix Tables A1 to A7) are deposited together in a public GitHub repository, archived with a permanent identifier through Zenodo: repository [URL to be added]; archived version [Zenodo DOI to be added]. The supplementary tables listed in the Appendix are provided as downloadable files from the Zenodo archive; all reported values come from a single analysis run (CRC_DTP_20260815_1705), whose complete output and session information are included in the archive. The drug-tolerant persister signature (the Up and Down gene sets) was generated by the Atlasi Laboratory and is withheld pending its primary publication, with which it will be released.
