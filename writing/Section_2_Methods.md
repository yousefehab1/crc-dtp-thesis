# 2. Materials and Methods

The analysis was built as one shared core, signature definition, expression processing, single-sample scoring, clinical endpoints and a common statistical toolkit, applied to three modules that differ only in their data and their module-specific tests. This section describes the shared core once and then each module. All gating thresholds are held in a single configuration file and are stated here with their exact values, so that the analysis can be reproduced without reference to the code. The overall flow of data through the pipeline is shown in Figure 1.

## 2.1 Data sources

Four transcriptomic resources were used, summarised in Table 2.1. The colorectal strand used two independent primary-tumour cohorts: GSE39582 (Marisa et al. 2013), profiled on the Affymetrix HG-U133 Plus 2.0 microarray and retrieved with GEOquery, and TCGA-COAD, RNA-seq quantified by STAR and retrieved from the Genomic Data Commons with TCGAbiolinks. Only primary tumours were used in both the colorectal and pan-cancer arms, so the TCGA-COAD sample set is defined identically wherever it appears. The pan-cancer strand extended the same TCGA RNA-seq pipeline to the wider atlas of solid-tumour cohorts. The metastasis strand used GSE50760 (Kim et al. 2014), paired RNA-seq of matched normal mucosa, primary tumour and liver metastasis from the same patients. Clinical follow-up for all TCGA cohorts came from the TCGA Clinical Data Resource (Liu et al. 2018). Two non-solid projects, TCGA-LAML and TCGA-DLBC, were excluded a priori because the drug-tolerant persister concept does not apply to them.

## 2.2 Signature definition

The drug-tolerant persister programme was defined from a master signature panel generated by the Atlasi laboratory and not yet published. Three scores were derived from it: an up-regulated component (Up, 313 genes), a down-regulated component (Down, 398 genes), and a Composite defined as Up minus Down. Six further gene sets were carried in parallel as reference programmes, each taken from its original publication so that the specificity of the DTP result could be judged against defined transcriptional states rather than against arbitrary sets: a fetal intestinal programme, a revival stem cell programme (revSC), a regenerative stem cell programme (RSC), a crypt-base columnar cell programme (CBC), a MYC target module, and an inflammatory bowel disease epithelial programme (IBD). Their sources, sizes and derivations are given in Table 2.4.

The fetal intestinal set (302 genes) comprised the genes up-regulated in fetal intestinal spheroids relative to adult enteroids (Mustata et al. 2013), with the colonic counterpart of Yui et al. (2018) as support. The revSC set (396 genes) was the revival stem cell cluster of Ayyaz et al. (2019), taken as the positive markers of that Lgr5-negative, non-proliferative population. The regenerative stem cell (RSC, 233 genes) and crypt-base columnar cell (CBC, 366 genes) sets were taken from Vasquez et al. (2022). The MYC module (240 genes) combined the HALLMARK_MYC_TARGETS_V1 and V2 sets from MSigDB (Liberzon et al. 2015). The IBD epithelial set (129 genes) was the pan-epithelial inflamed-versus-healthy signature of Smillie et al. (2019), restricted to the epithelial identity so that it reflected epithelial regeneration rather than immune or stromal infiltration.

A gene set was scored in a given expression matrix only if at least 70 percent of its member genes were present in that matrix, and the realised coverage was logged for each set. Because the panel and every expression matrix were first mapped to a single gene-identifier namespace (Section 2.3), the number of genes actually scored is slightly smaller than the source count above. This fractional coverage gate protects cross-platform comparability, because a score built from a small and variable fraction of its genes is not comparable between the microarray and RNA-seq matrices.

## 2.3 Expression processing

Each platform was normalised to a single convention, a log2-scale, gene-indexed matrix, before scoring. Microarray intensities for GSE39582 were mapped from probes to genes with the platform annotation, and duplicate genes were collapsed in log space by averaging. TCGA RNA-seq counts were transformed to transcripts per million and then to log2(TPM + 1), with duplicate genes averaged in log space. The GSE50760 FPKM values were transformed to log2(FPKM + 1); additive sub-features were summed before the log transform and other duplicates averaged. A single gene-identifier namespace was enforced: both the signature gene sets and every expression matrix were converted to Ensembl gene identifiers, using a cached organism-wide map, before single-sample scoring, so that identifiers always matched at scoring time. The one exception is the molecular subtype classifiers (Section 2.7), which require gene symbols and were therefore fed a separately prepared log2 symbol matrix rather than the Ensembl matrix, avoiding any double transformation of the expression values.

## 2.4 Signature scoring

Signatures were scored with single-sample gene set enrichment analysis (ssGSEA; Barbie et al. 2009), implemented in GSVA (Hänzelmann et al. 2013). ssGSEA is a within-sample rank statistic: it ranks all genes in a sample and asks whether a signature's genes concentrate toward the top of that ranking, so the score reflects the coordinated expression of the set relative to the rest of the transcriptome in that same sample. Each score column was named by its signature with an ssGSEA suffix. Because the statistic depends only on the within-sample gene ranking, any monotonic transform of the input, such as the log2 convention adopted here, leaves the score unchanged, which is what makes the per-platform processing of Section 2.3 safe. Scoring is deterministic under the global seed; the only stochastic step in the pipeline is tie-breaking within the gene set enrichment analysis of Section 2.9.

## 2.5 Clinical endpoints

Two endpoints were analysed, overall survival and recurrence. For the TCGA cohorts both came from the TCGA Clinical Data Resource; for GSE39582 they came from the series' own survival and relapse-free annotation. The TCGA recurrence endpoint was the progression-free interval (PFI), the broad-coverage endpoint recommended for pan-cancer use by the Clinical Data Resource (Liu et al. 2018); the disease-free interval was available as a colorectal sensitivity option but was not used for the reported analyses. The same PFI endpoint was applied to TCGA-COAD in both the colorectal and pan-cancer arms, so recurrence is defined identically wherever TCGA appears. All time-to-event data were converted from days to months once at load. Outcomes were analysed at a 36-month landmark: each patient was classified by status at three years, giving Dead versus Alive and Recurred versus Recurrence-Free labels, with a censoring-aware derivation that treats a patient censored before the landmark as unclassifiable rather than event-free. The landmark trades some sample size for correct classification of early events, a limitation returned to in the Discussion.

## 2.6 Statistical analysis

Three complementary tests were applied throughout, and their gates are given in Table 2.2. The screen used the Mann-Whitney (Wilcoxon rank-sum) test comparing the score between outcome groups, reported as the rank-biserial effect size, which is bounded and comparable across cohorts. Kaplan-Meier curves with the log-rank test, using a split at the score median, were used for display only. Inference used a Cox proportional-hazards model on the continuous score. Because an ssGSEA score occupies a narrow numeric range, the hazard ratio for a one-unit change is not interpretable, so hazard ratios are reported per one standard deviation of the score within the cohort, obtained by rescaling the Cox coefficient, and the model concordance index is reported alongside. Multiple testing was controlled by the Benjamini-Hochberg false-discovery-rate procedure. The choice of which tests form a correction family is a considered decision rather than a fixed convention, because the false-discovery rate is defined only relative to the set of tests grouped together: a narrow family groups few tests and corrects gently, a pooled family groups many and corrects harshly, and the same raw p-value can therefore be significant under one grouping and not another. The families used here are the narrow, per-stratum groupings set out in Table 2.3, chosen so that each biological question is corrected within its own set of tests rather than diluted against unrelated ones. Because this is a choice and not a fact of the data, three safeguards were adopted. Both raw and corrected p-values are reported throughout, so a reader can apply a different family if preferred. The confirmatory conclusion, the primary colorectal association and its independence from clinicopathology and subtype, is one that survives even conservative correction and does not depend on the family definition. And results that sit near the 0.05 boundary, such as the whole-cohort overall-survival contrasts in TCGA-COAD, are treated as borderline and sensitive to the family rather than claimed as positive; the shift of the TCGA-COAD recurrence screen from a corrected 0.032 to 0.064 when the reference-signature panel changed, with no change in the underlying data, is a direct illustration of that sensitivity and is noted where it arises. The open question of narrow per-stratum versus pooled project-wide correction is revisited in the Discussion.

Table 2.2. Statistical gating thresholds, applied identically across all modules.

| Threshold | Value | Applied to | Rationale |
|---|---|---|---|
| Minimum group size | 10 per group | Mann-Whitney screen | Unstable effect sizes below this |
| Minimum arm size | 5 per High/Low arm | Kaplan-Meier display | Avoids single-patient arms |
| Minimum events | 5 | Kaplan-Meier and Cox | Too few events to estimate |
| Minimum n | 10 | Cox model | Model stability |
| Minimum events per variable | 10 | Adjusted and interaction Cox | Peduzzi et al. 1996 |
| Minimum cohort size | 100 | Pan-cancer cohort inclusion | Reliable within-cohort estimate |
| Minimum gene coverage | 70% | Signature scoring | Cross-platform comparability |

## 2.7 Molecular subtyping and adjustment

Consensus molecular subtypes were called with CMScaller (Eide et al. 2017), and pathway-derived subtypes with PDSclassifier. Both classifiers were given the log2 symbol matrix of Section 2.3. CMScaller was run in its already-log2 mode so that identical median-centring and scaling were applied to both cohorts. PDSclassifier assigns a sample to PDS1, PDS2 or PDS3 only when that subtype's posterior probability exceeds 0.6 and labels the remainder Mixed; the package default threshold was kept rather than tuned, which left about 21 percent of samples Mixed in both cohorts, and the classifier was pinned to a fixed version for reproducibility. Whether the score itself differs across subtypes was tested with the Kruskal-Wallis test, reported as the epsilon-squared effect size.

Two distinct Cox families addressed two different questions about the score's relationship to clinicopathology, and they should not be confused; both are illustrated in Figure 2.

The first family is the adjusted, or confounding, model. Its question is whether the score carries prognostic information beyond the established variables, or whether its apparent effect is merely a restatement of stage, microsatellite status or molecular subtype. Each adjusted model added the continuous score to a covariate-only model (clinicopathology, then CMS, then PDS in turn) fitted on the same patients. Three quantities were read from it: the change-in-estimate, the percentage by which the score's own log hazard ratio moved once the covariates were present, which measures how much of the score's effect the covariates absorb; the likelihood-ratio test comparing the model with the score against the covariate-only model, which asks whether the score improves fit; and the model concordance. A score that keeps a stable coefficient and a significant likelihood-ratio test after adjustment is adding independent information.

The second family is the interaction, or effect-modification, model. Its question is different: not whether the score adds information on average, but whether its effect differs between subgroups. Each interaction model compared a model containing the score-by-modifier product term against the additive model of the same two variables, by likelihood-ratio test; a significant interaction means the score's hazard ratio is not the same across the levels of that modifier. The modifiers tested were CMS, PDS, stage and microsatellite status. Both Cox families were gated by an events-per-variable rule of at least ten events per estimated parameter (Peduzzi et al. 1996), so that models were fitted only where the data could support them; this gate is stricter than the univariable one and is why several subgroups are reported as not testable.

## 2.8 Pan-cancer batch correction

For the pan-cancer strand, cancer type is a genuine batch, because a score compared across tissues confounds biology with tissue-of-origin expression. Batch correction with removeBatchEffect (limma), using cancer type as the batch, was therefore applied to the pooled score matrix only, to produce the single cross-tissue aggregate estimate. The per-cohort associations were left uncorrected, since within a cohort there is no cross-tissue batch to remove. This produces two distinct correction families for the false-discovery procedure, the per-cohort tests and the batch-corrected aggregate, which are corrected separately (Table 2.3).

## 2.9 Metastasis differential expression

Differential expression in GSE50760 used a paired design in limma (Ritchie et al. 2015), with patient as a blocking factor, on the log2(FPKM + 1) matrix, giving two contrasts from a single fit: normal versus primary, and primary versus metastasis. Because liver metastases carry adjacent hepatic tissue, a naive primary-versus-metastasis comparison confounds tumour biology with liver contamination. A liver-specific gene score was therefore used as a contamination proxy, its per-patient trajectory across the three tissues serving as a negative-control check, and a purity-adjusted sensitivity model added that score as a covariate. Signature enrichment along the axis was tested by gene set enrichment analysis on the ranked moderated statistic (clusterProfiler; Yu et al. 2012; Subramanian et al. 2005), using the signature panel as gene sets. The primary-versus-metastasis enrichment was computed on the liver-adjusted ranking, whereas the normal-versus-primary enrichment was left unadjusted because neither of those tissues contains liver.

## 2.10 Reproducibility

A single global seed was set at the start of every run. Each run created its own timestamped output directory, and an on-disk cache stored the downloaded and processed objects so that re-runs are deterministic and require no repeated downloads. The session information, including all package versions, was captured to a file in each run directory and is provided in the appendix. Every gating threshold used anywhere in the analysis is defined in one configuration file, so that a reader can inspect all of the decisions in Table 2.2 and Table 2.3 in a single place.

| Score across subtype (Kruskal-Wallis) | 3.3 | Within the subtype-comparison set | Separate question from survival |
